      Smart Flow

      Enter / Tab flow

      • Scene Heading → Enter: Action
      • Action → Enter: Action · Tab: Character
      • Character → Enter: Dialogue · Tab: Parenthetical
      • Dialogue → Enter: Action · Tab: Parenthetical
      • Parenthetical → Enter: Dialogue
      • Transition → Enter: Scene Heading
      • Enter on an empty Character/Dialogue/Parenthetical drops back to Action instead of stacking blank lines.
      • Backspace on an empty line first reverts it to Action, then merges it away. Backspace at the start of a line merges it into the line above.
